# Week 1

## Intro to Cryptography

Fundamental objective of cryptography is to enable people for a secure communication over a public channel in such a way that an opponent or evil actor cannot understand what is being said. Art of Secret Writing.

## CryptoSystem

P Set of possible plaintext/ Plaintext space C Set of possible ciphertext K Key Space E Set of all possible encryption algorithms D Set of all possible decryption algorithms

For every $$k \in K$$, such that $$e_k \in E$$ and $$d_k \in D$$.
